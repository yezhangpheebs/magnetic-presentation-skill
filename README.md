# 磁场计划专属演示 Magnetic Presentation

供 Codex 使用的完整演示模板技能。无需 collaborator 权限即可下载。

## 下载

前往 [最新版本下载页](https://github.com/yezhangpheebs/magnetic-presentation-skill/releases/latest)，下载 Assets 中的 **magnetic-presentation-skill.zip**。

请下载上述完整安装包；GitHub 自动生成的 Source code ZIP 不包含 PowerPoint 模板。

## 安装

1. 解压完整安装包。
2. 将 `skills/artifact-template-magnetic-presentation` 整个文件夹复制到 Codex 的技能目录。本模板原 Windows 安装位置为 `%USERPROFILE%\.codex\skills\`。如你的 Codex 使用其他位置，请让 Codex 安装该文件夹。
3. 新开 Codex 对话，确认技能可用。
4. 确保 Presentations 功能可用，并安装模板使用的字体。

使用示例：`使用 $artifact-template-magnetic-presentation，根据我提供的资料制作可编辑的设计汇报。`

## 安装包内容

- SKILL.md：汇报结构、设计规则和工作流程。
- artifact-template.json：模板与预览的相对路径。
- assets/reference.pptx：完整可编辑 PowerPoint 模板和案例参考。
- assets/preview.png：模板预览。
- agents/openai.yaml：技能显示配置。

请保持完整文件夹结构，并另存项目成果，保留原始模板。
