# Magnetic Presentation Skill

Reusable Magnetic Project presentation template for Codex.

The complete skill package contains SKILL.md, artifact-template.json, agents/openai.yaml, assets/preview.png and assets/reference.pptx.

## Installation

Copy the complete artifact-template-magnetic-presentation folder into your Codex skills directory. For the originating Windows installation this is %USERPROFILE%\.codex\skills\.

Start a new Codex chat, ensure the Presentations capability is available, then invoke $artifact-template-magnetic-presentation with your project brief and source files.
