# 磁场计划专属演示 Magnetic Presentation

供 Codex 使用的完整演示模板技能。公开下载，无需 GitHub 账号或 collaborator 权限。

## 下载完整安装包

[直接下载 magnetic-presentation-skill.zip](https://github.com/yezhangpheebs/magnetic-presentation-skill/releases/download/v1.0.0/magnetic-presentation-skill.zip)

[版本与安装说明](https://github.com/yezhangpheebs/magnetic-presentation-skill/releases/latest)

完整安装包约 34.1 MB，包含原始 PowerPoint 模板、预览、技能规则与配置。请下载上述安装包；Code > Download ZIP 和自动生成的 Source code 不包含模板资产。

## 安装

1. 解压完整安装包。
2. 将 `skills/artifact-template-magnetic-presentation` 整个文件夹复制到 Codex 的技能目录。本模板原 Windows 安装位置为 `%USERPROFILE%\.codex\skills\`。如你的 Codex 使用其他位置，请让 Codex 安装该文件夹。
3. 新开 Codex 对话，确认技能可用。
4. 确保 Presentations 功能可用，并安装模板使用的字体。

使用示例：`使用 $artifact-template-magnetic-presentation，根据我提供的资料制作可编辑的设计汇报。`
